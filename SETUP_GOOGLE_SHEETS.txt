GOOGLE SHEETS SYNC – co změnit

Tento update dělá dvě věci:
1) GitHub Action už nečte ručně nahraný XLSX. Rozpis zápasů čte přímo z Google tabulky:
   https://docs.google.com/spreadsheets/d/17rInHjZsT-sP6QSTcK4YhjQqo44TUzMCG7FjMASHjrY/
   list gid=116203339

2) Když v aplikaci uložíš výsledek, D1 zůstane hlavní databáze a výsledek se zároveň zapíše
   do stejného Google Spreadsheetu do listu „CB BUTchers výsledky“.
   Je to schválně samostatný list, aby skript nepoškodil původní rozpis.

SOUBORY K NAHRAZENÍ
- scripts/build_events.py
- config/sources.json
- .github/workflows/update-calendar.yml
- cloudflare/src/index.js
- requirements.txt

NOVÝ SOUBOR
- google-apps-script/Code.gs

A) GOOGLE APPS SCRIPT
1. Otevři danou Google tabulku.
2. Rozšíření -> Apps Script.
3. Obsah Code.gs nahraď souborem google-apps-script/Code.gs.
4. V Apps Scriptu otevři Project Settings -> Script Properties.
5. Přidej:
   SYNC_SECRET = nějaký dlouhý náhodný řetězec
   Např. neukládej tento příklad: 2ad... (vytvoř vlastní).
6. Deploy -> New deployment -> Web app.
7. Execute as: Me.
8. Who has access: Anyone.
   Bezpečnost zápisu/čtení řeší SYNC_SECRET.
9. Zkopíruj URL web app, obvykle https://script.google.com/macros/s/.../exec

B) GITHUB SECRETS
Repository -> Settings -> Secrets and variables -> Actions.
Přidej:
- GOOGLE_SHEETS_WEBAPP_URL = URL z kroku A9
- GOOGLE_SHEETS_SYNC_SECRET = stejná hodnota jako Apps Script SYNC_SECRET

ICAL_URL a IMPORT_TOKEN zůstávají beze změny.

C) CLOUDFLARE WORKER SECRETS
V cloudflare/ spusť:
  npx wrangler secret put GOOGLE_SHEETS_WEBAPP_URL
  npx wrangler secret put GOOGLE_SHEETS_SYNC_SECRET

Do prvního vlož URL Apps Script web app.
Do druhého úplně stejný SYNC_SECRET.

Potom deploy:
  npm run deploy

D) TEST ČTENÍ
Na GitHubu:
Actions -> Aktualizace kalendare -> Run workflow

V logu má být např.:
  Google Sheets: 8 zápasů

Ručně nahraný sources/Brnensky_pohar_2026_27.xlsx už build_events.py nepoužívá.
Můžeš ho z repozitáře odstranit.

E) TEST ZÁPISU
1. V aplikaci otevři zápas.
2. Zadej výsledek.
3. Výsledek zůstane v D1 / statistikách.
4. V Google tabulce se automaticky vytvoří list „CB BUTchers výsledky“
   a objeví se v něm zápis.

POZNÁMKA K PŮVODNÍ TABULCE
Výsledek se zapisuje do samostatného listu „CB BUTchers výsledky“, ne přímo do buněk rozpisu.
To je bezpečnější, protože bez přesné znalosti významu výsledkových buněk původního rozpisu by mohl automatický zápis přepsat cizí data.
